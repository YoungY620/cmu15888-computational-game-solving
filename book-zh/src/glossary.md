## #

<a id="jianzhi"></a>
**α-β 剪枝（alpha-beta pruning）**　
不改变返回值地剪去不可能影响决策的子树。

α-β 剪枝在保持返回值与 minimax 完全一致的前提下剪去不可能影响最终决策的子树：维护 MAX 方已能保证的最好得分 α 与 MIN 方的 β，一旦某节点越出该窗口就不必再搜索。最好情形下只需检查约 2b^(d/2) 个终止位置，同等算力下可比 minimax 多搜一倍深度；着法排序与迭代加深是逼近最好情形的关键。

*首次讲解：[L2 完全信息博弈 1：树搜索](ch02-perfect-info-1.html)*

<a id="houhui"></a>
**Φ-后悔（Φ-regret）**　
由一族策略偏移 Φ 参数化的事后理性度量。

Φ-后悔以偏移族 Φ 参数化：比较学习者的累计效用与"每轮先施加偏移 φ 再行动"的累计效用之差；偏移集越丰富，诱导的事后理性概念越强——常值偏移对应外部后悔，全部偏移对应交换后悔。凸博弈中还存在严格加细的谱系 Φ_EXT ⊂ Φ_EF ⊂ Φ_LIN ⊂ Φ_FE ⊂ Φ_SWAP。Gordon 等人的框架把 Φ-后悔最小化归约为不动点计算加偏移集上的外部后悔最小化。

*首次讲解：[L6 相关均衡与 Φ-后悔](ch06-phi-regret.html)*


## A

<a id="aivat"></a>
**AIVAT（AIVAT）**　
Pluribus 对抗实验使用的方差缩减评估方法。

Pluribus 与顶尖人类职业选手的对抗实验使用 AIVAT [Burch et al., AAAI-18] 做方差缩减，成绩以毫大盲/局报告，统计显著性用 95% 置信度的单尾 t 检验判定。经 AIVAT 调整后，Pluribus 在"5 名职业选手对 1 个 Pluribus"的实验中平均赢 48±25 mbb/game，以统计显著性获胜（p = 0.028）。

*首次讲解：[L16 Pluribus：多人无限注德州扑克](ch16-pluribus.html)*

<a id="alphastar"></a>
**AlphaStar（AlphaStar）**　
联赛训练加优先化虚构自对弈的星际争霸 II 宗师级智能体。

AlphaStar 采用联赛训练：智能体最初从人类比赛录像中监督学习以解决探索问题，随后在一个由智能体组成的联赛中互相比赛。主智能体用优先化虚构自对弈（PFSP），按对手对自己的胜率成比例地选择对手——对手越强越可能被选中；主利用者负责找出主智能体的潜在破绽，联赛利用者负责发现整个联赛的系统性弱点。AlphaStar Final 在天梯上超过 99.8% 的人类排名玩家、达到宗师级别，但后来被发现仍存在可被利用的弱点。

*首次讲解：[L21 双预言机方法（DO/PSRO）](ch20-double-oracle.html)*


## B

<a id="blackwellkejiejinxing"></a>
**Blackwell 可接近性（Blackwell approachability）**　
让向量支付的平均值趋近目标锥的重复博弈框架。

Blackwell 可接近性把后悔最小化表述为一个向量支付的重复博弈：支付向量的第 i 个分量是相对"总是采取动作 i"的后悔变化量，目标是让平均支付趋近非正锥。按 Blackwell 定理的构造性证明，每一轮选取一个包含目标集的半空间并迫使支付落入其中。用 FTRL 选择要迫使的半空间产生的迭代与后悔匹配完全一致，用 OMD 则与 RM+ 完全一致。

*首次讲解：[L4 标准式博弈：LP、FTRL 与后悔匹配](ch04-normal-form.html)*

<a id="blummansoursuanfa"></a>
**Blum–Mansour 算法（Blum–Mansour algorithm）**　
把交换后悔归约为逐动作外部后悔的算法。

该算法为每个动作维护一个外部后悔最小化器，以其输出为列组成随机矩阵，并输出该矩阵诱导马尔可夫链的平稳分布作为自己的策略；观测效用后把按当前策略缩放后的效用分发给各最小化器。其交换后悔以 O(√(T|A|log|A|)) 为界，所有玩家各自运行时平均相关博弈分布收敛到相关均衡。

*首次讲解：[L6 相关均衡与 Φ-后悔](ch06-phi-regret.html)*

<a id="banfenlishenyu"></a>
**半分离神谕（semi-separation oracle）**　
返回期望不动点或越界证据的析取型神谕。

半分离问题要求计算以下二者之一：φ 的一个 ε-期望不动点，或一点 x 使 φ(x) ∉ X。它把 Gordon 框架与 EAH 所需的"分离神谕加不动点"放松为二者的析取，从而容许那些不把策略集映回自身的函数。配合收缩壳集与椭球法，可对多项式维度的非线性偏离（含低次多项式偏离）最小化 Φ-后悔并以 poly(n, m, k, log(1/ε)) 计算 Φ-均衡。

*首次讲解：[L7 最小化 Φ-后悔：非线性偏离](ch07-nonlinear-deviations.html)*

**标准式博弈（normal-form game）**　
行列对应纯策略、格子给出收益向量的博弈表示。

标准式（又称矩阵式或策略式）中，行与列分别对应各参与人的纯策略，每个格子给出该策略组合下的收益向量。任何有限博弈都可以表示为标准式，但从扩展式转成矩阵式会发生组合爆炸：Θ(m) 个节点的博弈可产生 2^m 个纯策略，因此标准式表示往往是低效的。

*首次讲解：[L1 导论](ch01-introduction.html)*

<a id="buwanmeihuiyichouxiang"></a>
**不完美回忆抽象（imperfect-recall abstraction）**　
允许抽象博弈中的玩家忘记不再相关区分的抽象。

完美回忆的抽象迫使玩家在后轮区分他在前轮就能区分的一切信息，即使该区分在后轮已毫无战略意义；不完美回忆允许忘记这类不再相关的区分，把各轮的抽象解耦，大幅降低抽象计算与均衡求解的开销。代价是理论保证的丧失：CFR 类算法在不完美回忆博弈中没有收敛保证，行为策略纳什均衡甚至可能不存在。但实践中，使用不完美回忆抽象的扑克程序始终稳定优于使用完美回忆抽象的程序。

*首次讲解：[L10 博弈抽象 1](ch10-abstraction-1.html)*

<a id="buwanmeixinxiboyi"></a>
**不完美信息博弈（imperfect-information game）**　
参与人不完全知道他人与自然已采取行动的博弈。

大多数现实博弈都是不完美信息博弈，因为参与人并不完全知道其他参与人和自然已经做了什么。不完美信息带来额外问题：需要理解私有信息与信号、处理欺骗与诈唬，针对完美信息博弈的技术（如 AlphaZero）在这里不适用。石头剪刀布只有同时行动——等价地，后行动者看不到先行动者的选择——才有真正的策略内容。

*首次讲解：[L1 导论](ch01-introduction.html)*

**CFR+（CFR+）**　
负后悔置零、平均策略按 t² 加权的 CFR 变体。

CFR+ 把后悔地板到零（负后悔直接置零），并在平均策略中把迭代 t 按 t² 加权；在 DCFR 族中对应参数 (∞, −∞, 2)。它曾是实践中最快的 CFR 变体，但对早期坏迭代不做折扣：在含极端次优动作的玩具例子中需要 471,407 次迭代才能学会正确动作，而线性 CFR 只需 970 次。CFR+ 与蒙特卡洛采样配合不佳。

<a id="celvekongjianfanyingyuyanji"></a>
**策略空间反应预言机（policy-space response oracles (PSRO)）**　
元求解器加强化学习近似最优反应的统一框架。

PSRO（Lanctot et al., NeurIPS 2017）是双预言机和虚拟博弈在概念上的统一推广：元求解器在由经验博弈论分析构造的元博弈上输出元策略——取纳什均衡退化为 DO，取均匀平均退化为虚拟博弈；最优反应则用强化学习近似计算，策略由神经网络参数化，种群是一个不断增长的策略库。把 ADO 的受限博弈定义搬到元求解器上即得 Anytime PSRO。AlphaStar 的联赛训练与 OpenAI Five 的历史对手混合都是 PSRO 式的设计。

*首次讲解：[L21 双预言机方法（DO/PSRO）](ch20-double-oracle.html)*

<a id="chengxingquanzhonggengxin"></a>
**乘性权重更新（multiplicative weights update (MWU)）**　
按累计效用的指数成比例选行动的在线算法。

MWU 是取负熵正则化子的 FTRL：每个行动的概率正比于 exp(η·累计效用)，又称指数权重或随机加权多数，是被研究得最透彻的在线算法。其后悔界为 2√(T ln m)，在对抗效用序列下已知是最优的；另有以总权重为势函数的直接证明：每轮恰好有 η 倍期望损失比例的总权重被移除。

*首次讲解：[L4 标准式博弈：LP、FTRL 与后悔匹配](ch04-normal-form.html)*

<a id="chouxiangbingtai"></a>
**抽象病态（abstraction pathology）**　
更细的抽象反而给出更差原博弈解的现象。

直觉上"抽象越精细，解越好"并不成立：存在零和博弈的例子，删除攻击者一个动作的较细抽象给出的策略远离原博弈均衡，而同时删除双方各一个动作的更粗抽象反而恰好给出均衡策略。这类病态在小型扑克博弈中同样存在，说明抽象质量是非单调的。

*首次讲解：[L11 博弈抽象 2](ch11-abstraction-2.html)*

<a id="chouxiangdingli"></a>
**抽象定理（abstraction theorem）**　
把提升策略的可利用度界分解为映射误差加精化误差。

Kroer 与 Sandholm（NeurIPS-18）的统一框架把原博弈到抽象博弈的映射分解为两步：先映到抽象博弈的完美回忆精化，再粗化信息集。定理给出 ε′ᵢ = ε + 映射误差ᵢ + 精化误差ᵢ，两项各自分解为收益误差与分布误差；分解是精确的（不等号仅来自抽象博弈未被精确求解），但一般为事后形式、依赖最优反应。在分布相似条件下恢复为可事前计算的界，且比先前工作指数级地更好。

*首次讲解：[L11 博弈抽象 2](ch11-abstraction-2.html)*

<a id="cuxiangguanjunheng"></a>
**粗相关均衡（coarse correlated equilibrium (CCE)）**　
玩家在收到推荐之前就承诺不偏离的相关分布。

相关分布 μ 是粗相关均衡，如果对任意玩家与偏离行动，遵从分布的期望效用不劣于单方面换成该固定偏离行动。它要求玩家在收到任何推荐之前就承诺不偏离；纳什均衡总是粗相关均衡——纳什均衡可视为不相关的（粗）相关均衡。外部后悔的自对弈收敛到粗相关均衡。

*首次讲解：[L4 标准式博弈：LP、FTRL 与后悔匹配](ch04-normal-form.html)*

**DREAM（DREAM）**　
用结果采样加基线方差缩减的 Deep CFR 变体。

DREAM（Steinberger et al., 2020）是 Deep CFR 的流行变体：改用结果采样，并为缓解重要性采样的方差引入自举基线方差缩减技术。由于基线不完美、自举过程中仍会递归地除以采样概率，其估计器方差依然很高；在 Dark Chess 等大型博弈上，DREAM 与 NFSP 相对随机对手已无任何优势，显著逊于 ESCHER。

<a id="deepcfr"></a>
**Deep CFR（Deep CFR）**　
用神经网络近似各信息集反事实后悔的 CFR。

Deep CFR 为每名玩家维护一个后悔网络，对每个信息集输出各动作反事实后悔的近似值，寄希望于神经网络在相似信息集之间的泛化能力，从而摆脱人工抽象；另维护一个策略网络近似平均策略，博弈树的外部采样遍历负责收集训练数据。其可靠性定理把函数近似误差显式纳入收敛界：近似误差只以平方根形式进入渐近地板，误差趋零时算法收敛到纳什均衡。

*首次讲解：[L17 博弈求解中的深度学习](ch17-deep-learning.html)*

<a id="daixiangguandetuanduijixiaojidajunheng"></a>
**带相关的团队极小极大均衡（team min-max equilibrium with correlation (TMECor)）**　
允许团队私有随机性相关化策略的凸化 TME。

TMECor 允许团队成员在赛前利用团队私有随机性相关化各自的策略：协调装置从联合分布中抽取一个联合纯计划，各队员照此执行；这里不需要激励相容约束，因为队员天然共享收益。TMECor 是凸的双线性鞍点问题，极小极大定理成立；通信博弈中 TMECor 值 1/2 严格大于 TME 的 1/4。计算 TMECor 即使对单方团队也是 NP-完全的，团队对团队时为 Δ₂^P-完全。

*首次讲解：[L18 团队博弈](ch18-team-games.html)*

<a id="dongzuochouxiang"></a>
**动作抽象（action abstraction）**　
对连续或巨大的动作空间做离散化的抽象。

无限注德扑的下注空间本质上是连续的（任意数额直至全下），必须离散化为有限个动作。第一个带最优性保证的动作抽象算法用后悔转移热启动的梯度上升在线优化下注尺度：在当前参数处做无悔学习、用有限差分估计梯度、移动参数并转移后悔，重复至收敛。结合逆向映射后，阈值化与纯化前需先把细粒度动作归并为元动作（fold/call/bet），避免概率质量被稀释惩罚。

*首次讲解：[L11 博弈抽象 2](ch11-abstraction-2.html)*

**ESCHER（ESCHER）**　
固定参考策略、直接估计条件价值的结果采样方法。

ESCHER（McAleer et al., 2023）为每名玩家使用一个固定的参考策略，用神经网络估计条件价值而非反事实价值：估计是反事实价值乘以一个固定缩放因子 r_i(j)，而后悔匹配的缩放不变性保证迭代不受影响。由此完全消除重要性采样及其高方差，函数近似误差也只以线性可加项进入后悔；它还是完全无模型的。实践中 ESCHER 显著优于 DREAM 等流行算法。

**反事实后悔最小化（counterfactual regret minimization (CFR)）**　
在每个决策点独立最小化反事实后悔的算法族。

CFR 最早由 Zinkevich 等人（NIPS 2007）提出：每个决策点运行一个局部后悔最小化器（最常用后悔匹配及其变体），由反事实效用驱动——反事实效用度量"假设玩家设法让自己到达该信息集"时各行动的价值。总后悔以各局部后悔的正部之和为界，关于信息集个数只是线性的。双人零和博弈中双方的时间平均策略收敛到极小极大均衡；CFR 是近二十年博弈求解众多突破性成果的核心算法。

*首次讲解：[L5 展开式博弈 1：CFR](ch05-efg-cfr.html)*


## G

<a id="gameshrink"></a>
**GameShrink（GameShrink）**　
在信号树上合并同构节点的无损抽象算法。

GameShrink 分两步：自底向上在信号树（每条边对应自然向玩家揭示一个信号的事件）上运行动态规划，标记所有同构节点对；再自顶向下对互为兄弟的同构节点执行抽象变换（合并）。同构关系刻画节点间的战略对称性，算法运行时间为 Õ(n²)。定理保证：抽象博弈中的纳什均衡解释回原博弈仍是纳什均衡。它一秒钟完成 31 亿节点罗得岛德州扑克的无损抽象，使其成为当时被精确求解的最大不完美信息博弈。

*首次讲解：[L10 博弈抽象 1](ch10-abstraction-1.html)*

<a id="gensuizhengzehualingdaozhe"></a>
**跟随正则化领导者（follow the regularized leader (FTRL)）**　
在累计效用目标上加入严格凸正则化子的在线算法。

FTRL 在虚拟博弈的累计效用目标上减去一个严格凸正则化子（除以学习率），向策略中注入随机性使对手更难利用学习者；学习率趋于无穷时退化为虚拟博弈。取负熵正则化子即得乘性权重更新，取欧几里得正则化子得投影更新。其后悔界为 R/η + ηΣ‖u^(t)‖²_*，最优调节学习率后为 2B√(RT)。

*首次讲解：[L4 标准式博弈：LP、FTRL 与后悔匹配](ch04-normal-form.html)*

<a id="gongyouzhishiziboyi"></a>
**共有知识子博弈（common-knowledge subgame）**　
由信息集递归连通关系定义的公共知识闭包子博弈。

同一层的两个节点若存在某个信息集把一节点的后代与另一节点的后代连在一起则称为连通；节点处的共有知识子博弈由所有与它递归连通的节点及其后代组成，恰好囊括"双方都确知双方……确知当前可能处于其中"的所有节点。以往的安全子博弈求解方法都建立在共有知识子博弈之上；但在战争迷雾象棋等博弈中，共有知识集合的规模可超过 10^12，基于它的方法完全不可行。

*首次讲解：[L15 知识受限子博弈求解（KLSS）](ch15-klss.html)*

<a id="guanghuaboyi"></a>
**光滑博弈（smooth game）**　
集体改打福利最优分量可保住最优福利份额的博弈。

称一个博弈关于福利最优策略组合是 (λ, μ)-光滑的，若对每个策略组合，各玩家改打自己在福利最优组合中的分量后，集体能保证 λ·OPT − μ·SW。Roughgarden 证明许多重要博弈类都是光滑的，某种意义上它是零和博弈的推广。在 (λ, μ)-光滑博弈中，无悔动力学总能保证最优福利的 λ/(1+μ) 份额，这一比值称为鲁棒无政府代价；OMD 要么收敛到近似纳什均衡，要么平均福利严格超出该份额。

*首次讲解：[L8 乐观主义与最终迭代收敛](ch08-optimism.html)*


## H

<a id="houhui"></a>
**后悔（regret）**　
与事后最优固定策略的累计效用之差。

后悔定义为事后看来用某个固定策略能获得的最优累计效用，减去学习者 T 轮的实际累计效用。若在线算法在任意对抗选取的效用序列下都满足 Reg^(T) = o(T)，则称其为无后悔算法。后悔可以为负；任何确定性在线算法都无法避免线性后悔，随机化是无后悔性质的本质要素。

*首次讲解：[L4 标准式博弈：LP、FTRL 与后悔匹配](ch04-normal-form.html)*

<a id="houhuidianlu"></a>
**后悔电路（regret circuits）**　
把局部无悔算法组合到复合策略集上的构造。

后悔电路（Farina, Kroer & Sandholm, ICML 2019）回答：已知如何在某些集合上高效最小化后悔，能否把多个后悔最小化器组合起来应对复合而成的更复杂集合。笛卡尔积的后悔等于各分量后悔之和；凸包的后悔至多是混合器后悔与各分支最大后悔之和。把两种电路与序列形式多胞体的归纳分解相结合，即得序列形式多胞体上的高效无悔算法——这正是 CFR。

*首次讲解：[L5 展开式博弈 1：CFR](ch05-efg-cfr.html)*

<a id="houhuipipei"></a>
**后悔匹配（regret matching (RM)）**　
按正累计后悔的比例选择行动的无参数算法。

后悔匹配按正比于正累计（反事实）后悔的方式选取策略，是无参数且尺度不变的在线算法。其分析利用勾股引理：瞬时后悔始终与迄今累计的正后悔正交，从而后悔不超过 √(mT)。Hart 与 Mas-Colell 的原始结果针对更强的内部后悔；实践中后悔匹配及其变体是 CFR 中最常用的局部后悔最小化器。

*首次讲解：[L4 标准式博弈：LP、FTRL 与后悔匹配](ch04-normal-form.html)*

<a id="houhuipipei"></a>
**后悔匹配+（regret matching+ (RM+)）**　
每次更新把负后悔截断为零的后悔匹配变体。

RM+ 由 Tammelin（2014）提出：与后悔匹配的唯一区别是每次更新时把负后悔截断为 0。它与 RM 享有类似的后悔保证，但实践中通常远优于 RM。Farina 等人（2021）揭示：在某个提升空间上，RM+ 是镜像下降的实例而 RM 是 FTRL 的实例——两者之间的差异是本质的。

*首次讲解：[L4 标准式博弈：LP、FTRL 与后悔匹配](ch04-normal-form.html)*

<a id="houhuizhuanyi"></a>
**后悔转移（regret transfer）**　
收益改变后缩放旧后悔值以热启动的技术。

当博弈收益改变而拓扑结构不变时，朴素地把旧后悔值搬到新博弈会因量纲不匹配而停滞，重新开始则浪费已有计算。正确做法是把转移过来的后悔值与用于平均的累计策略按 O(1/(1+δ√T)²) 缩放去权重：扰动越大、已运行越久，旧数据的可信度越低。这使热启动后均衡误差继续稳步下降，并支撑了抽象参数（如下注尺度）的在线优化。

*首次讲解：[L11 博弈抽象 2](ch11-abstraction-2.html)*

<a id="hunhecelve"></a>
**混合策略（mixed strategy）**　
智能体自行选定的、定义在纯策略上的概率分布。

不完美信息博弈可能需要混合策略——智能体自行选定的、定义在纯策略上的概率分布。一个基本事实是：在混合策略均衡中，出现在混合支撑里的每个纯策略带来的期望效用都相等。纯策略是给每个信息集指定一个行动的映射，其数目随信息集个数指数增长，因此混合策略的表示并不紧凑。

*首次讲解：[L1 导论](ch01-introduction.html)*


## J

<a id="jiaohuanhouhui"></a>
**交换后悔（swap regret）**　
允许全部策略映射作为偏移的最强经典后悔。

交换后悔取偏移集为全部 m^m 个映射，它同时上界外部后悔与内部后悔。交换后悔恒非负（偏移集包含恒等映射），这一性质使其成为一般和博弈中近似最优后悔分析的关键。Blum–Mansour 算法把交换后悔最小化归约为 |A| 个外部后悔最小化问题，后悔界为 O(√(T|A|log|A|))。

*首次讲解：[L4 标准式博弈：LP、FTRL 与后悔匹配](ch04-normal-form.html)*

<a id="jieguocaiyang"></a>
**结果采样（outcome sampling）**　
对所有玩家都采样、用重要性采样校正的 MCCFR。

结果采样对每个玩家的策略都采样：按参考策略与其余玩家策略的乘积分布采一个终结节点，再用重要性采样校正，每轮只需 O(d·|A|) 时间（d 为博弈树深度）。代价是方差正比于最小采样概率的倒数。它不要求知道对手的策略，因此可用作扩展式博弈中的在线后悔最小化算法，思路与标准式博弈中的 Exp3 如出一辙。

*首次讲解：[L17 博弈求解中的深度学习](ch17-deep-learning.html)*

<a id="jingxiangxiajiang"></a>
**镜像下降（mirror descent (MD)）**　
在贴近上一策略与优化上次效用之间权衡的在线算法。

镜像下降的更新规则在"针对上一次观察到的效用做优化"与"以 Bregman 散度度量、保持接近上一个策略"之间取得平衡。欧几里得正则化子生成平方欧氏距离（此时即在线梯度下降），负熵生成 KL 散度。在 Legendre 正则化子下镜像下降与 FTRL 等价，并享有几乎相同的后悔界。

*首次讲解：[L4 标准式博弈：LP、FTRL 与后悔匹配](ch04-normal-form.html)*

<a id="jixiaohuajidasousuo"></a>
**极小化极大搜索（minimax search）**　
MAX/MIN 层交替取最大最小回传值的树搜索。

minimax 是求解完全信息零和博弈的基本算法：MAX 方在每个自己的节点选择使值最大的后继，MIN 方选择使值最小的后继，叶节点的值由评估函数给出，值逐层向上回传。理论研究揭示了搜索深度病理：在某些模型上，回传值反而比启发式评估值本身更不可信。

*首次讲解：[L2 完全信息博弈 1：树搜索](ch02-perfect-info-1.html)*

<a id="jixiaojidadingli"></a>
**极小极大定理（minimax theorem）**　
零和博弈中先亮出混合策略的一方不吃亏。

von Neumann（1928）的极小极大定理表明：max_x min_y u₁(x,y) = min_y max_x u₁(x,y)，哪一方先亮出自己的混合策略都无所谓，这个共同值称为博弈值。定理还有凸分析形式（鞍点定理）：对紧致凸集上的连续凹-凸函数，max min 与 min max 相等。线性规划对偶直接蕴含该定理。

*首次讲解：[L1 导论](ch01-introduction.html)*

<a id="jiyuhouhuidejianzhi"></a>
**基于后悔的剪枝（regret-based pruning (RBP)）**　
动态剪掉零概率或负后悔动作子树的技术。

不完美信息博弈中的剪枝必须是动态（暂时）的：此刻无用的分支以后可能重新相关。部分剪枝剪掉对手到达概率为零的路径；区间与总体基于后悔的剪枝进一步剪掉自身零概率动作，剪枝结束时用对对手（区间或总体）平均策略的反事实最优反应（CBR——即使在自己到达不了的信息集上也最大化反事实价值的策略）一次性补齐被跳过的迭代。总体 RBP 还能把所需空间降到与未剪枝信息集的数量成正比。

*首次讲解：[L9 CFR 加速技术](ch09-cfr-speedups.html)*

<a id="jizhisheji"></a>
**机制设计（mechanism design）**　
拥有承诺能力的一方设计博弈规则以优化目标。

机制设计中拍卖者不知道买方估值，需要设计机制使买方如实报价构成均衡。Myerson（1981）证明：估值独立同分布时，存在保留价 r 使"最高报价超过 r 则最高报价者赢得物品并支付次高报价与 r 的最大者"最大化期望收益。最优机制可统一写成：拍卖者的一个策略，使得固定该策略后直接策略组合（如实报告）是其他玩家的纳什均衡。

*首次讲解：[L19 自动化机制设计](ch19-mechanism-design.html)*

**库恩定理（Kuhn's theorem）**　
完美回忆下混合策略与行为策略收益等价。

库恩定理表明：若智能体具有完美回忆，则对每个混合策略都存在一个收益等价的行为策略，且该等价是双向的，因此求均衡时可以只考虑行为策略；定理对无限博弈同样成立。该结论在非完美回忆博弈中不成立：存在混合策略能保证 1/2 而任何行为策略只能保证 1/4 的例子。

*首次讲解：[L1 导论](ch01-introduction.html)*

<a id="kuozhanshiboyi"></a>
**扩展式博弈（extensive-form game）**　
用博弈树显式表示行动顺序与收益的博弈表示。

扩展式（亦称树式）用博弈树显式表示行动顺序：每个节点标明由谁行动，叶节点给出各参与人的收益，并含一个按固定分布行动的机会玩家。与之相对的矩阵式表示会发生组合爆炸，这正是本课程大量算法直接在扩展式上工作的原因。

*首次讲解：[L1 导论](ch01-introduction.html)*

<a id="kuozhanshixiangguanjunheng"></a>
**扩展式相关均衡（extensive-form correlated equilibrium (EFCE)）**　
调解人在博弈过程中逐步私下建议行动的均衡。

EFCE（von Stengel & Forges, 2008）中，调解人在博弈过程中逐步私下建议行动。把调解人写成增广博弈时，其纯策略等于给原博弈每个信息集指派一个行动，混合策略等于纯策略组合上的分布；由于调解人在后续信息集中记不得自己早先发出的建议，调解人是不完美回忆的——这正是最优 EFCE 为 NP 难的原因。EFCE 可看作信息设计加上隐私约束：调解人不能把一个玩家的信息透露给别的玩家。

*首次讲解：[L19 自动化机制设计](ch19-mechanism-design.html)*

**蓝图策略（blueprint strategy）**　
离线粗抽象中预先算好的、为实时精解提供上下文的策略。

Libratus 等系统的框架是：离线在一个粗抽象中求解整个博弈得到蓝图策略，它近似地为每个局面提供上下文（到达概率、各类型对手的期望价值等）；对局中再以蓝图为上下文，在更细的抽象中实时求解当前到达的子博弈。Libratus 的抽象把博弈从 10^161 个决策点压缩到约 10^12 个，蓝图给出前两轮的详细策略与后两轮的粗略策略——后两轮由子博弈求解器实时精解。

**乐观在线学习（optimistic online learning (OFTRL/OMD)）**

**Maxmargin 精解（Maxmargin refinement）**　
最大化最小边际以尽量压低对手进入价值的精解。

Maxmargin 对每种对手类型定义边际 Margin = EV[Alt] − EV[Enter]，求解时最大化最小边际，而 Re-solve 只是力图让所有边际非负。它的问题是会在蓝图已经惩罚过的类型上浪费求解力度。Libratus 实际使用的 Estimated-Maxmargin 改用蓝图给出的估计值而非上界作为 Alt 支付：估计误差不超过 Δ 时，整体可利用性至多比"只在子博弈集合内改动的最优策略"高 2Δ。

<a id="mengtekaluocfr"></a>
**蒙特卡洛 CFR（Monte Carlo CFR (MCCFR)）**　
每轮只遍历博弈树采样部分的 CFR 随机近似。

MCCFR 把精确效用替换为无偏的稀疏估计器：把终结节点集划分为若干块，每轮以一定概率采样一个块，只更新被采样路径上的信息集，每轮迭代代价远低于原版 CFR。只要估计器条件无偏，随机后悔最小化的后悔相对其确定性内核只有 √T 量级的额外退化（由鞅差序列加 Azuma–Hoeffding 不等式证明）。Libratus 的蓝图策略即由 MCCFR 的改进版计算。

**蒙特卡洛树搜索（Monte Carlo tree search）**　
通过随机模拟迭代构建部分搜索树的前瞻搜索框架。

MCTS 不试图展开整棵博弈树，而是迭代地构建一棵部分搜索树，把计算集中在最有前途的分支上；每次迭代包含选择、扩展、模拟、反向传播四个阶段，树策略负责探索与利用的权衡，默认策略负责把对局模拟到底。AlphaGo 用价值网络压缩搜索深度、策略网络压缩宽度；AlphaGo Zero 进一步把 MCTS 本身用作策略改进算子：搜索产出的着法分布是对网络原始输出的改进，网络再向它学习。

<a id="nashenjunheng"></a>
**纳什均衡（Nash equilibrium）**　
没有任何参与人有动机单方面偏离的策略组合。

策略组合是纳什均衡，当且仅当在他人不偏离的前提下，没有任何参与人有动机单方面偏离。占优策略均衡必是纳什均衡，反之不然。纳什均衡可能不唯一（需精炼、聚点等机制），纯策略意义下也可能不存在；Nash（1950）证明任何有限博弈在允许混合策略时至少存在一个纳什均衡。

*首次讲解：[L1 导论](ch01-introduction.html)*

<a id="neibuhouhui"></a>
**内部后悔（internal regret）**　
只允许把某动作一律换成另一动作的偏移后悔。

内部后悔只允许"把某个动作一律换成另一个动作、其余不动"的偏移，共 |A|(|A|−1) 个单点交换映射。由于任一交换偏移的增益可以按原先动作分解，交换后悔至多为内部后悔的 |A| 倍，因此在是否次线性的意义上两者等价。内部后悔次线性的自对弈收敛到相关均衡。

*首次讲解：[L4 标准式博弈：LP、FTRL 与后悔匹配](ch04-normal-form.html)*

<a id="nixiangyingshe"></a>
**逆向映射（reverse mapping (action translation)）**　
把对手抽象外的动作映回抽象动作集的转译。

对手可能采取抽象中不含的动作（如任意下注额），需要动作转译把对手的实际动作映射到抽象中邻近的动作。好的映射应满足端点保持、单调性、尺度不变性与连续性；伪调和映射 f(x) = (B−x)(1+A)/((B−A)(1+x)) 从一个简化扑克博弈的纳什均衡推导而来，满足全部期望性质，显著优于随机几何映射。问题在于对手可以专门挑选翻译后对我方最不利的注额——翻译本身可被利用。

*首次讲解：[L11 博弈抽象 2](ch11-abstraction-2.html)*

## Q

<a id="qiantaoziboyiqiujie"></a>
**嵌套子博弈求解（nested subgame solving）**　
对手走出树外行动时实时求解新子博弈的技术。

真实对手可以下任意注额，即走出抽象树之外的行动；传统动作翻译把树外注额映射回树内，而对手可以专门挑选翻译后对我方最不利的注额。嵌套子博弈求解的思想是：对手每走出一个树外行动，就实时为这个行动求解一个新的增广子博弈，Alt 支付取该类型最优树内行动的价值；定理保证所得策略在包含新行动的新抽象中维持 ε-均衡，且该过程可对每个后续树外行动重复嵌套。实验上它较动作翻译把可利用性降低一个数量级以上。DeepStack 独立提出的持续重解与之类似，但没有礼物机制，也不在手牌之间更换行动抽象。

*首次讲解：[L13 Libratus（中）：子博弈求解](ch13-libratus-2.html)*

<a id="qiwangbudongdian"></a>
**期望不动点（expected fixed point）**　
只要求 φ(x)−x 的平均很小的分布型不动点。

分布 μ 称为 φ 的 ε-期望不动点，如果 φ(x)−x 在 μ 下期望的范数不超过 ε——只要求平均很小，不要求逐点很小。与真实不动点不同，期望不动点可以高效计算：反复施加映射后求和发生望远镜式相消，O(1/ε) 次迭代即可。用期望不动点替换 Gordon 框架中的真实不动点，允许学习者输出混合策略即可绕过不动点计算的难处理性（该计算与求纳什均衡等价）。

*首次讲解：[L7 最小化 Φ-后悔：非线性偏离](ch07-nonlinear-deviations.html)*

**RVU 性质（RVU (regret bounded by variation in utilities)）**　
后悔由预测误差界定并含策略变差负项的性质。

RVU（效用变差有界后悔）性质要求：存在常数 α, β, γ > 0 使后悔 ≤ α + βΣ‖u^(t) − m^(t)‖²_* − γΣ‖x^(t) − x^(t−1)‖²。与通常的后悔界相比有两处不同：后悔由预测误差界定，且出现一个负项——策略变化越剧烈后悔反而越小。OFTRL 与 OMD 都满足 RVU 性质；在后悔之和非负的博弈（含双人零和与多矩阵零和博弈，后者由图上各边的双人零和博弈组成）中，它给出 O(1) 的个体后悔与有界的二阶路径长度（各轮策略变差的平方和）。

*首次讲解：[L8 乐观主义与最终迭代收敛](ch08-optimism.html)*

<a id="resolvejingjie"></a>
**Re-solve 精解（Re-solve refinement）**　
给对手拿走蓝图价值的退出选项的安全精解。

Re-solve 精解在增广子博弈根部让对手的每种类型在 Enter（进入子博弈，按新求解的策略对局）与 Alt（拿走蓝图策略下进入子博弈的期望价值）之间选择。由于对手只会在 Enter 价值不超过 Alt 时进入，该构造保证对手进入子博弈的 EV 不高于蓝图，从而新策略的可利用性不超过蓝图。代价是它可能错过明显的改进机会——构造只要求对手的 EV 不超过蓝图水平，没有动力消除残留的次优打法。

*首次讲解：[L13 Libratus（中）：子博弈求解](ch13-libratus-2.html)*

<a id="reachmaxmarginjingjie"></a>
**Reach-maxmargin 精解（Reach-maxmargin refinement）**　
把对手到达子博弈时已犯错误计入替代支付的精解。

若对手某类型在蓝图中到达子博弈的 EV 低于她在别处的可得价值，她到达子博弈这一事实本身就说明她犯了错，差额是她赠送给我们的礼物（gift）；于是可以把该类型的 Alt 替代支付相应提高而不破坏安全性，求解器得以集中精力压低其他类型的 EV。多个子博弈同时精解时，礼物按各子博弈被到达的概率分配，并用礼物的下界替代名义值。实验上它把可利用性较蓝图压低约一个数量级且保持安全。

*首次讲解：[L13 Libratus（中）：子博弈求解](ch13-libratus-2.html)*

<a id="renyishikeshuangyuyanji"></a>
**任意时刻双预言机（anytime double oracle (ADO)）**　
保证可利用度单调不增的双预言机变体。

ADO 为每个玩家分别定义一个受限博弈：己方只能用种群中的策略，而对手可以使用整个博弈中的任意策略。由于受限分布是在对手不受限的最坏情形下求出的，每次加入新策略后可利用度不会上升，从而可以在训练的任意时刻安全停止。其大规模实现 RM-BR DO 利用后悔最小化加最优反应：策略集巨大的一方只需要一个最优反应预言机，因为该方的后悔不依赖于其动作集的大小。

*首次讲解：[L21 双预言机方法（DO/PSRO）](ch20-double-oracle.html)*


## S

<a id="stackelbergjunheng"></a>
**Stackelberg 均衡（Stackelberg equilibrium）**　
领导者承诺策略、跟随者最优响应的均衡。

Stackelberg 均衡是领导者的一个策略，使得固定领导者策略后，直接策略（服从建议）是跟随者的最优响应。承诺能力带来巨大收益：课程例子中唯一纳什均衡只给领导者 1，而领导者承诺以接近 1/2 的概率出 X 后，跟随者的最优响应变为 Y，领导者期望效用约为 10.5。忽略领导者自身激励约束时它是"对领导者最优的均衡"，加上激励约束则变为最优纳什均衡问题。

*首次讲解：[L19 自动化机制设计](ch19-mechanism-design.html)*

<a id="shangzhixinjie"></a>
**上置信界（upper confidence bound (UCB)）**　
选择上置信区间上界最大臂的老虎机策略。

多臂老虎机中每个选择节点可以看成在多条臂之间平衡试新与择优；经典 UCB 为每条臂维护一个置信区间，总是选择上置信界最大的臂，把探索与利用统一在同一个标量准则里。把 UCB 用作树策略就得到 UCT：未访问过的子节点权重为无穷大，保证每个子节点至少被探索一次；采用 UCT 动作选择的 MCTS 能够找到最优策略（Kocsis & Szepesvári, ECML-06）。

*首次讲解：[L3 完全信息博弈 2：MCTS 与 AlphaGo](ch03-mcts.html)*

<a id="shendushouxianqiujie"></a>
**深度受限求解（depth-limited subgame solving）**　
有限前瞻加叶子处对手续局策略选择的搜索。

不完美信息博弈中状态没有良好定义的值：一个信息集的值取决于双方在整个博弈其余部分的策略，因此朴素截断会被对手针对。深度受限求解在每个叶子节点允许对手做最后一次行动、在多个续局策略中选择，并迭代地"求解子博弈 → 计算最优响应 → 加入策略集合"；该迭代算法在二人零和博弈中收敛到纳什均衡。它把完美信息博弈"有限前瞻 + 叶子估值"的搜索范式推广到不完美信息博弈：Modicum 与 Pluribus 都建立在其上。

*首次讲解：[L16 Pluribus：多人无限注德州扑克](ch16-pluribus.html)*

<a id="shenjingxuniziduiyi"></a>
**神经虚拟自对弈（neural fictitious self-play (NFSP)）**　
用深度强化学习实现最优响应预言机的虚拟博弈。

NFSP 维护两个神经网络：价值网络用 Q-learning 训练以给出近似最优响应——这正是虚拟博弈所要求的；策略网络用监督学习模仿玩家过往行为以捕捉平均策略，因为虚拟博弈中只有平均策略才收敛。玩家行动时在近似最优响应与平均策略之间按一定比例混合。NFSP 是评估大型博弈深度学习方法时的常用基线，也是 Deep CFR 的先驱。

*首次讲解：[L17 博弈求解中的深度学习](ch17-deep-learning.html)*

<a id="shinengganzhichouxiang"></a>
**势能感知抽象（potential-aware abstraction）**　
用转移到下一轮各桶的概率分布刻画手牌势能的抽象。

此前的抽象算法用假设不再下注时的获胜概率（期望手牌强度 EHS）作为手牌相似度，但它不能捕捉手牌的势能——听牌当前胜率不高，却有很大机会在后续轮次变成强牌，且 EHS 相同的手牌强度分布形态可能截然不同。势能感知抽象把每手牌表示为转移到下一轮各桶的概率直方图再聚类，从而捕捉多维势能。2014 年的最优算法进一步结合不完美回忆与高维推土机距离（把一个分布变成另一个的最小搬运代价）：一次自底向上扫描、无需整数规划，击败了此前最好的抽象。

*首次讲解：[L10 博弈抽象 1](ch10-abstraction-1.html)*

<a id="shuangrenlingheboyi"></a>
**双人零和博弈（two-player zero-sum game）**　
一方所赢即另一方所输的双人博弈。

零和博弈中两个玩家利益完全对立：对所有行动组合有 u₁ = −u₂。它具有其他博弈所不具备的优美性质：均衡可交换（不存在均衡选择问题）、均衡策略集构成有界凸多胞形、纳什均衡恰好是极小极大问题的解，且可用线性规划在多项式时间内求解。均衡策略保证博弈值，非均衡策略则可被利用。

*首次讲解：[L1 导论](ch01-introduction.html)*

<a id="shuangyuyanji"></a>
**双预言机（double oracle (DO)）**　
交替进行受限博弈求均衡与全博弈最优反应的框架。

双预言机方法（McMahan et al., ICML 2003）自始至终只维护一个受限的纯策略集合：求受限子博弈的纳什均衡，对每个玩家计算全博弈上的最优反应并加入策略集，直到最优反应间隙为零——此时受限均衡就是原博弈的纳什均衡。DO 保证终止于精确纳什均衡，但最坏情况需要指数多次迭代（即使在两人零和扩展式博弈中），且可利用度不是单调下降的。

*首次讲解：[L21 双预言机方法（DO/PSRO）](ch20-double-oracle.html)*

<a id="shuxingjuecewenti"></a>
**树形决策问题（tree-form decision problem (TFDP)）**　
取单玩家视角把其余玩家抽象掉得到的序贯决策问题。

TFDP 把展开式博弈中单个玩家面对的决策问题抽象出来：玩家在决策点选择行动、在观察点观察信号，二者构成一棵树。其序列形式策略集可用两种基本操作归纳分解：观察点对应笛卡尔积，决策点对应凸包。这一分解是后悔电路与 CFR 的结构基础。

*首次讲解：[L5 展开式博弈 1：CFR](ch05-efg-cfr.html)*

**通信均衡（communication equilibrium）**　
固定调解人策略后玩家策略构成纳什均衡的元组。

通信均衡是一个策略元组 (μ, x₁, …, xₙ)，使得固定调解人策略 μ 后所有玩家都在最优响应。Stackelberg 均衡、最优相关均衡、机制设计与信息设计都是扩展式博弈中最优通信均衡的特例。主定理（Zhang & Sandholm, NeurIPS 2022）给出了关于博弈树规模多项式的统一算法：显示原理把消息空间化为"如实报告 + 服从建议"，通信博弈经两个观察压缩到多项式规模，激励约束再经 LP 对偶化为单个线性规划。

*首次讲解：[L19 自动化机制设计](ch19-mechanism-design.html)*

<a id="tuanduiboyi"></a>
**团队博弈（team game）**　
共享效用函数的队友们在不能自由沟通下对抗对手。

团队博弈中多个玩家组成团队、共享同一效用函数，但不能自由沟通、不能共享私有信息。看似自然的解概念面临本质困难：团队成员各自独立随机化时无法共享一枚秘密硬币来协调彼此的随机选择，因此极小极大定理失效；纳什均衡也无法表达团队联合最优这一目标。团队博弈与（可定时的）不完美回忆双人零和博弈存在精确对应，而库恩定理在此不适用。

*首次讲解：[L18 团队博弈](ch18-team-games.html)*

<a id="tuanduijixiaojidajunheng"></a>
**团队极小极大均衡（team min-max equilibrium (TME)）**　
团队先承诺不相关策略组合的 max-min 解。

TME 是优化问题 max_{x₁,x₂} min_y u(x₁, x₂, y) 的解：团队成员各自独立混合，团队先承诺策略。这是非凸优化，因而困难，且极小极大定理不成立——通信博弈中 TME 值为 1/4，而交换 max 与 min 次序后得到 1/2。把解概念限制为 TME 可能造成任意大的效用损失；即便只求团队对给定对手策略的最优反应也已是 NP-难的。

*首次讲解：[L18 团队博弈](ch18-team-games.html)*

<a id="tuanduixinniandag"></a>
**团队信念 DAG（team belief DAG (TB-DAG)）**　
按团队公共知识化出的战略等价单玩家决策问题。

TB-DAG 把团队博弈表示为 DAG 上的单玩家决策问题：决策点由博弈树节点的集合（信念）标识，动作是在每个相交信息集上各选一个动作的处方，观察点按公共观察分裂。它与原团队决策问题战略等价，DAG 版 CFR 可在其上高效运行。其规模由信息不对称度 k（末信息集个数，度量有多少信息为某个队员所知而非全队公共知识）主导：每轮迭代时间 ≤ (b+1)^k·poly(N)，k 有界时即多项式，且在 ETH 下不可改进。

*首次讲解：[L18 团队博弈](ch18-team-games.html)*

## W

<a id="waibucaiyang"></a>
**外部采样（external sampling）**　
只对对手与机会玩家的策略采样的 MCCFR 变体。

外部采样独立地为对手与机会玩家各采样一个纯策略，由此得到的效用估计器是无偏的；每轮只需更新被采样路径可达的信息集。在标准式博弈中它把每轮代价从 O(nnz(A)) 降为 O(m₁+m₂)，给出 Grigoriadis–Khachiyan 次线性算法：求 ε-均衡的时间甚至少于读入整个输入。对平衡博弈其每轮代价为 O(√|H|)，渐近优于原版 CFR。

*首次讲解：[L17 博弈求解中的深度学习](ch17-deep-learning.html)*

<a id="waibuhouhui"></a>
**外部后悔（external regret）**　
偏移集只含常值映射时的 Φ-后悔。

外部后悔是在线学习中最标准的后悔概念，对应偏移集只含常值映射——即与事后最优固定策略比较。外部后悔小并不意味着交换后悔小：存在外部后悔为零而交换后悔线性增长的效用序列（MWU 即有此性质）。外部后悔的自对弈收敛到粗相关均衡。

*首次讲解：[L4 标准式博弈：LP、FTRL 与后悔匹配](ch04-normal-form.html)*

<a id="wanmeihuiyi"></a>
**完美回忆（perfect recall）**　
同一信息集内各节点的历史序列一致。

玩家具有完美回忆，如果对所有属于同一信息集的节点，其到达路径上自己的信息集与行动序列都相同。直觉上，完美回忆意味着玩家从不忘记此前获得的信息。它是 Kuhn 定理与 CFR 等绝大部分理论的前提；在不完美回忆博弈中行为策略纳什均衡甚至可能不存在。

*首次讲解：[L5 展开式博弈 1：CFR](ch05-efg-cfr.html)*

**伪调和映射**　见 [逆向映射](#nixiangyingshe)。

<a id="wuwangtuoqiusuanfa"></a>
**无望椭球算法（ellipsoid against hope (EAH)）**　
在保证不可行的对偶规划上运行椭球求相关均衡的算法。

EAH 由 Papadimitriou 和 Roughgarden（2008）首次提出：在不可行的对偶规划上执行椭球算法，每步用"足够好响应"（GER）神谕产生一点反驳候选点，椭球体积收缩到指数级小之后，由极小极大定理从小得多的零和博弈中读出对偶不可行性的证书——一个 ε-Φ-均衡。它在多人博弈中以 log(1/ε) 的多项式时间计算（粗）相关均衡；对线性偏离，偏离的不动点恰好实现 GER。

*首次讲解：[L7 最小化 Φ-后悔：非线性偏离](ch07-nonlinear-deviations.html)*


## X

<a id="xiangguanjunheng"></a>
**相关均衡（correlated equilibrium (CE)）**　
玩家在看到推荐行动之后仍不愿偏离的相关分布。

相关均衡（Aumann 1974）允许偏移函数依赖于所推荐的行动（交换偏移），因此是比粗相关均衡更强的概念：Nash ⊆ CE ⊆ CCE。两个概念都可以用调解人解释：调解人先从相关分布中采样一个联合行动组合，再把对应行动作为建议私下告诉每位玩家。与纳什均衡形成鲜明对照的是，相关均衡可以用线性规划在多项式时间内求得；内部或交换后悔的自对弈收敛到相关均衡。

*首次讲解：[L6 相关均衡与 Φ-后悔](ch06-phi-regret.html)*

<a id="xianshiyuanli"></a>
**显示原理（revelation principle）**　
任何通信均衡都等价于一个直接通信均衡。

显示原理表明：对任意通信均衡，存在一个等价的直接通信均衡——玩家发给调解人的消息是对私有信息的报告且均衡中总是如实报告，调解人发给玩家的消息是行动建议且均衡中总是被服从。证明是模拟论证：新调解人在内部模拟旧调解人与原均衡策略，针对直接均衡的任何偏离都一一对应于针对原均衡的偏离。它把无限的消息空间约减为"类型报告 + 行动建议"的有限结构。

*首次讲解：[L19 自动化机制设计](ch19-mechanism-design.html)*

<a id="xianxingcfr"></a>
**线性 CFR（linear CFR (LCFR)）**　
把迭代 t 的后悔与平均策略贡献按 t 加权的 CFR。

线性 CFR 对早期坏迭代的后悔和平均策略进行折扣：迭代 t 按 t 加权，在 DCFR 族中即 DCFR_{1,1,1}。它把含极端次优动作的玩具例子的收敛从 471,407 次迭代降到 970 次，而最坏情形收敛界只增加一个小常数因子。与 CFR+ 和 DCFR 不同，线性 CFR 与蒙特卡洛采样配合得很好（折扣 MCCFR）；Pluribus 即使用 Linear MCCFR。

*首次讲解：[L9 CFR 加速技术](ch09-cfr-speedups.html)*

<a id="xingweicelve"></a>
**行为策略（behavioral strategy）**　
在每个信息集上独立随机化的策略。

行为策略为智能体在自己的每个信息集上各指定一个关于行动的概率分布——边走边掷骰子，而非开局前一次性选定纯策略。其表示是紧凑的（维度等于序列数而非纯策略数），但效用关于自己的行为策略不是线性的、甚至不是凹的，这给优化带来根本困难。

*首次讲解：[L1 导论](ch01-introduction.html)*

<a id="xinxiji"></a>
**信息集（information set）**　
行动者无法区分的决策节点的集合。

为刻画不完美信息，每个玩家的决策节点集合被划分成若干信息集，同一信息集包含该玩家无法区分的所有节点，因此其中所有节点必须有相同的行动集合。行动者不知道自己处于集合中的哪个节点，因而无法针对对手的实际选择作答。信息集是不完美信息博弈的核心概念。

*首次讲解：[L1 导论](ch01-introduction.html)*

<a id="xinxisheji"></a>
**信息设计（information design (Bayesian persuasion)）**　
发送者承诺信号方案以影响接收者行动的设计问题。

信息设计又称贝叶斯劝说（Kamenica & Gentzkow, AER 2011）：状态按公共先验抽取，发送者承诺一个信号，接收者观察信号实现后用贝叶斯法则形成后验再采取最优行动。贝叶斯理性对信号诱导的后验分布只施加一个约束——贝叶斯可信性：后验的期望必须回到先验。最优信号的值恰为发送者间接效用函数的凹闭包在先验处的取值；发送者能严格获益于劝说当且仅当凹闭包严格大于原函数值。

*首次讲解：[L19 自动化机制设计](ch19-mechanism-design.html)*

<a id="xujucelve"></a>
**续局策略（continuation strategy）**　
给出深度受限子博弈叶子之后完整打法的策略。

深度受限求解中，每个续局策略给出叶子之后的完整打法，从而确定叶子值；对手在叶子处在多个续局策略中选择，使搜索者找到的策略更平衡——若搜索者打出不平衡的策略，对手切换到另一个续局策略就会惩罚它。Pluribus 取 k=4：预计算的蓝图策略、偏向弃牌、偏向跟注与偏向加注的蓝图变体。

*首次讲解：[L16 Pluribus：多人无限注德州扑克](ch16-pluribus.html)*

<a id="xuliexingshi"></a>
**序列形式（sequence form）**　
用路径概率乘积表示策略、使效用线性的表示。

序列形式向量的每个分量存放从根到某信息集采取某行动的路径上玩家自己各概率的乘积；合法策略由概率流量守恒约束刻画，构成约束数为博弈规模多项式的凸多胞体，序列数关于博弈树规模是线性的。其关键优点是：每个玩家的效用关于自己的序列形式策略是线性的。由此零和展开式博弈可用博弈树规模的多项式时间 LP 求极小极大均衡。

*首次讲解：[L5 展开式博弈 1：CFR](ch05-efg-cfr.html)*

<a id="xuniboyi"></a>
**虚拟博弈（fictitious play）**　
每轮对对手历史平均策略做最优反应。

虚拟博弈由 Brown（1951）提出：每个时刻各玩家对对手迄今为止的平均策略做最优反应，可以理解为最基本的对手建模。Robinson（1951）证明其时间平均在任何零和博弈中都收敛，但收敛速率可以指数级缓慢，且只有双方都遵循该算法时才收敛——若对手知道我们在用虚拟博弈，我们就会被利用。作为在线算法（跟随领导者），它不是无后悔的：存在使其蒙受线性后悔的效用序列。

*首次讲解：[L4 标准式博弈：LP、FTRL 与后悔匹配](ch04-normal-form.html)*


## Y

<a id="yincangjueseboyi"></a>
**隐藏角色博弈（hidden-role game）**　
好人团队不知道自己队友是谁的社交推理博弈。

隐藏角色博弈（又称社交推理博弈）中，好人团队不知道自己的队友是谁，博弈强调通信。其解概念——隐藏角色均衡——经分裂人格博弈定义：把每个玩家拆成好人版与坏人版两个角色，转化为 2n 人对抗性团队博弈；该概念本质上是非对称的。在私有通信、坏人少数派、坏人协调三条假设下存在高效算法（显示原理加 MPC 模拟中介者），放松任一假设分别有 NP、coNP、Σ₂^P 下界；应用上精确求解了 5 人与 6 人阿瓦隆。

*首次讲解：[L18 团队博弈](ch18-team-games.html)*

<a id="yucexinghouhuipipei"></a>
**预测性后悔匹配（predictive regret matching (PRM/PRM+)）**　
把预测引入后悔匹配框架的变体。

预测性后悔匹配用预测向量去猜测下一个后悔向量：出招前先用预测修正累计后悔再归一化。PRM 与 PRM+ 的后悔同样以预测误差为界，但不满足 RVU 性质。把 PRM+ 用作每个信息集的局部后悔最小化器、配合二次加权平均与交替更新即得 PCFR+：在非扑克基准博弈上它比 CFR+、DCFR、LCFR 快数个数量级，扑克类博弈上则 DCFR 仍然最快。

*首次讲解：[L8 乐观主义与最终迭代收敛](ch08-optimism.html)*


## Z

<a id="zengguangziboyi"></a>
**增广子博弈（augmented subgame）**　
以蓝图诱导分布为根部上下文的自洽子博弈。

在增广子博弈中，双方都从蓝图诱导的分布中取样：每次迭代对手被随机发一手私有牌，我方牌也按相应的条件概率分布发放，因此增广子博弈的根部分布完整地编码了蓝图提供的上下文。扑克中的不完美信息子博弈由玩家间的公共知识界定（例如由公共牌和到目前为止的行动序列），与公共知识一致的每个私有牌组合都是该子博弈的一个根。

*首次讲解：[L13 Libratus（中）：子博弈求解](ch13-libratus-2.html)*

<a id="zhanyoucelvejunheng"></a>
**占优策略均衡（dominant strategy equilibrium）**　
每个智能体都选择自己占优策略的策略组合。

占优策略是对所有对手策略组合都是最优响应的策略；每个智能体都选择占优策略的组合称为占优策略均衡。它的优点是不需要反投机：无论对手做什么，自己的选择都是最优的，囚徒困境中（背叛，背叛）即为一例。占优策略不总存在，被占劣的策略称为被支配策略。

*首次讲解：[L1 导论](ch01-introduction.html)*

<a id="zhekoucfr"></a>
**折扣 CFR（discounted CFR (DCFR)）**　
对正负后悔与平均策略分别折扣的 CFR 族。

DCFR 每次迭代把正后悔乘以 t^α/(t^α+1)、负后悔乘以 t^β/(t^β+1)，平均策略贡献按 (t/(t+1))^γ 加权；它把线性 CFR 与 CFR+ 统一为一个参数族。取 α=1.5、β=0、γ=2 时 DCFR 在实践中稳定优于 CFR+（在 HUNL 残局与 Goofspiel 上通常快 2–3 倍），最坏情形界只比 CFR 差一个小常数因子。让超参数随迭代线性变化（HS-DCFR）还能取得数量级的进一步加速。

*首次讲解：[L9 CFR 加速技术](ch09-cfr-speedups.html)*

<a id="zhishishouxianziboyiqiujie"></a>
**知识受限子博弈求解（knowledge-limited subgame solving (KLSS/KLUSS)）**　
只保留知识距离不超过 k 的节点来构造子博弈。

KLUSS 的思想是：在知识图中忽略太远的节点，只保留与当前位置知识距离不超过 k 的节点来构造子博弈；区别于旧版 KLSS，它不把被截断边界上的节点冻结为蓝图策略。理论上不安全——反例中可利用度可按博弈规模的线性因子增长——但实践中趋于安全；安全化途径包括更新蓝图、在祖先闭独立集上分配偏离、仿射均衡，以及按内部礼物分解边际的 Safe-1-KLSS 与对手受限的 OLSS。Obscuro 以 2-KLUSS 为核心成为战争迷雾象棋上首个超人类智能体。

*首次讲解：[L15 知识受限子博弈求解（KLSS）](ch15-klss.html)*

<a id="ziboyiqiujie"></a>
**子博弈求解（subgame solving）**　
对局中实时在更细抽象中精解当前到达局面的技术。

完美信息博弈中子博弈可以只用子博弈内部的信息独立求解；不完美信息博弈中这不成立——子博弈内的最优打法依赖到达分布与反事实价值，而这些由博弈其余部分内生决定。子博弈求解以蓝图为上下文构造自洽的增广子博弈并实时求解；不同技术的差别在于如何借助蓝图构造增广子博弈，以及由此得到的安全性保证的强弱。这是 Libratus 中最重要的技术。

*首次讲解：[L13 Libratus（中）：子博弈求解](ch13-libratus-2.html)*

<a id="zidongboyichouxiang"></a>
**自动博弈抽象（automated game abstraction）**　
把原博弈压缩为小博弈、求解后再映回的框架。

自动博弈抽象分三步：抽象算法把原博弈压缩成抽象博弈；均衡求解算法在抽象博弈上求出纳什均衡；逆向模型把抽象博弈的均衡解释为原博弈中的策略。抽象按是否损失信息分为无损与有损两类：无损抽象只合并战略上完全等价的节点，有损抽象则是攻克超大博弈的关键。

*首次讲解：[L10 博弈抽象 1](ch10-abstraction-1.html)*

<a id="ziduiyi"></a>
**自对弈（self-play）**　
博弈双方均采用后悔最小化算法的求解范式。

自对弈指让博弈双方都采用后悔最小化算法。零和博弈中只要双方都是无后悔的，平均策略就收敛到极小极大均衡，均衡精度 ε 等于双方平均后悔之和；对偶间隙（双方最优响应改进空间之差）随之以 O(1/√T) 收敛到 0。一般和博弈中，外部后悔的自对弈收敛到粗相关均衡，内部或交换后悔的自对弈收敛到相关均衡。

*首次讲解：[L4 标准式博弈：LP、FTRL 与后悔匹配](ch04-normal-form.html)*

<a id="ziwogaijinqi"></a>
**自我改进器（self-improver）**　
发现并修补蓝图动作抽象中最常被利用之洞的模块。

自我改进器是 Libratus 三模块中唯一在对局期间修改蓝图的模块：找出蓝图动作抽象中被对手利用最多的前 k 个洞，冻结策略其余部分，在两侧不对称的更粗抽象中为含新动作的局部计算 ε-均衡，再把新动作抽象并入蓝图。它不是对手建模——只用对手数据决定在哪里补洞，修补对所有对手普适。比赛期间它每晚运行，使职业选手找到的弱点往往在几天后就失效。

*首次讲解：[L14 Libratus（下）：自我改进器](ch14-libratus-3.html)*

<a id="zuizhongdiedaishoulian"></a>
**最终迭代收敛（last-iterate convergence）**　
算法迭代点本身（而非时间平均）收敛到均衡。

基于后悔的保证只给出时间平均意义下的收敛；传统无悔算法如 MWU 的迭代点即使在零和博弈中也不收敛——动力学围绕均衡持续盘旋甚至向外发散。带光滑正则化子的乐观镜像下降在后悔之和非负的博弈中以 T^(−1/2) 的速率使大部分迭代点成为近似纳什均衡，该速率是紧的。最终迭代收敛与近似最优后悔之间存在深刻联系。

*首次讲解：[L8 乐观主义与最终迭代收敛](ch08-optimism.html)*
